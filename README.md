# Amazon_Sales_Analysis

## Sobre o projeto

Projeto desenvolvido para praticar o fluxo completo de análise de dados utilizando Python e Power BI.

O objetivo é transformar um dataset bruto de produtos da Amazon em um dashboard interativo, passando pelas etapas de limpeza, preparação e análise dos dados.

## Tecnologias

- Python
- Pandas
- Jupyter Notebook
- Power BI

## Etapas

- [ ] Exploração do dataset
- [ ] Limpeza dos dados com Python
- [ ] Limpeza equivalente com Power Query
- [ ] Construção do dashboard
- [ ] Documentação dos insights

## Dataset

Amazon Products Dataset
